# Steffan Jones - Website

A clean, professional website for academic tutoring and university guidance services.

## Files Included

- `index.html` - Main homepage
- `tutoring.html` - Academic tutoring services page
- `college.html` - University guidance services page
- `payments.html` - Payments and booking information

## Setup Instructions

### For GitHub Pages:

1. Create a new repository or use your existing `steffanteach.github.io` repo
2. Upload all HTML files to the root directory
3. Create an `assets` folder for images
4. Add your images:
   - `assets/profile.jpg` - Your profile photo
   - `assets/harvard.png` - Harvard logo
   - `assets/seren.png` - Seren Network logo
5. Go to repository Settings > Pages
6. Set source to "Deploy from a branch"
7. Select "main" branch and "/ (root)"
8. Your site will be live at `https://steffanteach.github.io`

### Images to Add

Create an `assets` folder and add these images:
- **profile.jpg** - A professional photo of yourself (recommended size: 800x1000px)
- **harvard.png** - Harvard University logo (transparent background recommended)
- **seren.png** - Seren Network logo (transparent background recommended)

If you don't add images, the site will still work perfectly - the image placeholders will just be hidden.
